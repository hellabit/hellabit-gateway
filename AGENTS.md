# Hellabit Gateway

This is a new, isolated local foundation. The canonical owner checkout remains
the containing Playground root. Do not alter other products, shared feeds,
existing Hellabit sites, production bindings or provider accounts.

The core loopback service is standard-library only. The optional ASGI API and
encrypted recovery tools use the hash-locked Python dependencies; do not replace
their signature, TLS or encryption libraries with custom cryptography. Node
dependencies are development tools for compiling and exercising contracts in a private EVM.
All monetary quantities use integers in the explicitly named asset's units.
Never infer an asset from its display symbol or convert between currencies.

Bank and chain examples are synthetic. Keep live connections disabled until an
exact institution/network/asset/signer binding and independent settlement
readback have been enrolled. Never send funds, deploy contracts, issue a
redeemable coin or onboard a real customer as part of local verification.

One verification command: `python3 scripts/verify.py`. It owns focused tests,
contract proof, source packaging and one sanitized terminal receipt. Private
runtime and browser evidence never enter the source archive.

The public contract must distinguish software capability, local proof, external
connection readiness, real reserves and actual adoption. A contract reserve cap
is an assertion by a trusted attestor, not proof that bank reserves exist.
